Getting started

Getting started

Blum Studio is running. Connect your AI agent once, then just ask.

1. Connect your agents

Connect your agents in Settings: one click per agent, then restart the agent to use it. It registers Blum Studio where each agent looks. Your assistant can then create designs in any format, look at them, check them and export PNG or PDF files.

Prefer a terminal? Run npm run connect from the Blum Studio folder instead. Another MCP client (Cursor…)? Command node, argument server/dist/mcp.js in the Blum Studio folder, environment BLUM_ROOT set to that folder.

2. Ask for a design

Copy a prompt into your agent (Claude Code, Codex, Cursor or any MCP client): the design appears in Designs while it works.

Slow morning story

Make a story about a slow Sunday morning: warm coffee mood, a calm serif title, and the clinking-lattes photo.

Weekend sale post

Make a post for a weekend flash sale: a bold condensed title, "two days only", on a midnight blue wash.

3. Or design it yourself

Start from New story or New post in Designs, or open any design to edit it by hand. Stickers, fonts and photos are browsable in Resources; agents use the same catalogue.
